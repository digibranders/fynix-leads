## Project notes

- `params` and `searchParams` are Promises in pages, layouts and route handlers. Always `await` them; the sync access from Next 15 is only a deprecated fallback.
- Type params with the global `PageProps<'/route'>` and `LayoutProps<'/route'>` helpers, generated by `next dev` and `next build`, instead of hand-written types.
- Route groups `(name)` organize files only and do not change the URL. Two groups must not resolve to the same path.
- Layouts do not re-render on navigation, so do not read `searchParams` in a layout.
- Fonts come from `next/font/google`, set up in `app/layout.tsx` (Geist is the scaffold default).
- Next 16 renames `middleware` to `proxy`, drops `next lint` (the `lint` script runs `eslint`), and uses Turbopack by default. A custom `webpack` config fails `next build` unless you pass `--webpack`.
- Node 20.9 or newer is required. This machine runs Node 24.
