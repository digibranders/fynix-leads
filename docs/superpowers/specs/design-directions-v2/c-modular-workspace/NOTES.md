# C: Modular workspace

| Token | Value |
|---|---|
| Canvas | #EEECE7 |
| Surfaces | white raised; navy hero #0C1E2E; list pane navy 5% |
| Tints | navy 4% tiles, 6% inputs, 8% pressed; peach #E9AF88 at 30% for selection |
| Text | #0C1E2E, #2B3D4E, muted #4F5D69 (all 4.5:1 or better) |
| Radii | 22 panels, 20 pane, 16 tiles, 14 rows, 12 inputs, pill buttons and chips |
| Shadows | 1px ring at 6% + 3 layered navy-tinted blurs; selected card a smaller set |
| Type | Geist 15 base, 14 table, 12 small; Geist Mono refs; Geist Serif for titles and the hero figure only |
| Spacing | 8px grid, 16px gaps between modules |

**Premium:** every module is a different depth (canvas, tonal pane, raised white, one navy hero), so the arrangement reads before any text does. Shadows are layered and tinted to the navy. Buttons are pills with key hints.

**Separation:** zones come from tint and elevation, not outlines. Rows use inset 7% dividers, the table header is a tinted band, and actions sit in a pinned bar. Status always pairs an icon with a label.
